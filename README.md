# Hands-on-Matriz

- matrix01.java é um programa que lê 2 notas de 3 alunos e calcula a média;
- matrix02.java é um programa que lê uma matriz 3x3 de números inteiros, encontra o maior valor armazenado e mostra a posição em que o maior valor foi encontrado;
- matrix03.java é um programa que controla o estoque de uma pequena loja;
- matrix04.java é um programa que permite duas pessoas jogarem jogo da velha;
- matrix05.java é um programa que permite o usuário jogar jogo da velha contra o CPU;
